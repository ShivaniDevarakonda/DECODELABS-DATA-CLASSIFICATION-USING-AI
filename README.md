Data Classification Using AI

Project Overview

This project demonstrates data classification using Artificial Intelligence (AI) and Machine Learning. A Decision Tree Classifier is trained on the Iris dataset to classify flower species based on their features.

Objectives

- Learn the basics of data classification.
- Understand supervised machine learning.
- Train a Decision Tree model.
- Evaluate model performance using accuracy.

Technologies Used

- Python
- Scikit-learn
- NumPy
- Pandas (optional)

Dataset

The Iris dataset contains:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Classes:

- Setosa
- Versicolor
- Virginica

Installation

Install the required package:

pip install scikit-learn

Code Execution

Run the Python file:

python data_classification.py

Working Process

1. Load the Iris dataset.
2. Split data into training and testing sets.
3. Train a Decision Tree Classifier.
4. Predict classes for test data.
5. Calculate model accuracy.
